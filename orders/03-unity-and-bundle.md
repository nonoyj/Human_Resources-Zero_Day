# ORDER 03 -- UNITY, THE BUNDLE, AND WHAT RUNS WHERE

## Source of truth

- `unity/Assets/Content/desk_layout.json` is the layout's source. The copy under `Resources/` is generated by
  `publish_to_unity.py`; editing it by hand is undone on the next publish. (This cost a whole round once.)
- `art/kit/unity_sprites.json` is the manifest; `write_unity_metas.py` writes the `.meta` files.
- Every sprite the desk layout names must be `isReadable: 1` in **both** copies of its `.meta`, and listed in
  `ArtKitImporter.DeskLayers()`, or the tube's light silently skips it.

## The gates, and what "passed" means

| Gate | Command | Passing output |
|---|---|---|
| CoreTests | `dotnet run --project tools/CoreTests -c Release` | `ALL TESTS PASSED` |
| CompileCheck | `dotnet build tools/UnityStubs/CompileCheck.csproj -c Release` | `0 Error(s)` |
| Art pipeline | `.\scripts\Test-ArtPipeline.ps1` | `ART PIPELINE OK` |
| Publish | `python tools/art/publish_to_unity.py --verify` | `PASS: ... sha256 verified` |
| Twin | `python tools/comp/twin_desk.py --verify` | `PASS: ... layers + hotspots resolve` |
| Fresh clone | `python tools/verify_fresh_clone.py` | `PASS: a clean checkout of <sha> verifies itself` |

A gate that fails to **parse**, or fails for a reason unrelated to what it tests, is a bug in the gate and is
fixed in the same commit. (`Test-ArtPipeline.ps1` once ran a bare `dotnet build` in a folder with two project
files and reported a compile error that was not one.)

## The renderer that is NOT Unity

`tools/comp/twin_desk.py` reads the same JSON Unity reads and renders the composition offline. It proves the
data, not the engine. **Never** call it "in-engine". The in-engine proof is the player's screenshot.

## The offline light preview

`tools/comp/preview_screenlight.py` applies the same rule `ScreenLight.cs` applies and prints a measured
delta. It must read `art/kit/palette.json` (the menu's table) -- reading `make_art_kit.PALETTE` gave it an empty
ramp table and it reported "no change" while agreeing with a wrong `ScreenLight`. If the two disagree, the
**rule** is wrong, not the picture.

## The bundle

- Built by `/tmp/build_zip.py` (version string at the top). The zip is **git-ignored** (`*.zip`) but must exist
  in the repo for the player's script -- check it is committed before handing it over.
- Naming: `HR-ZeroDay-bundle-vNNN.zip`, sha256 quoted in the reply.
- The workspace must not accumulate stale bundles: delete the previous one when the new one is built.
