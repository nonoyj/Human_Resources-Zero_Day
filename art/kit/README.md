## Integration rules (FE)

1. **Import settings** (Project window -> select all -> Inspector):
   - Texture Type: `Sprite (2D and UI)`
   - Filter Mode: **Point (no filter)**
   - Compression: **None**
   - Mip Maps: **off**
   - Pixels Per Unit: **16**
   - Mesh Type: Full Rect (needed for 9-slice)
2. **9-slice:** set `Sprite Editor -> Border` to **8, 8, 8, 8** for the `*_9slice.png` files only.
3. **Palette:** do not recolour sprites in the editor; ask for a new variant so the palette stays law.
4. **No partial alpha** anywhere (verified by the checker). Use hard-edged transparency.
5. Backgrounds are drawn at exactly 480x270 and the camera is orthographic with a Pixel Perfect Camera
   component (`Assets Pixels Per Unit 16`, reference resolution 480x270, upscale RT off).

## AI artifact legend (`reference/artifact_legend.png`)

Same seed, same body, one artifact added. Left crop = human, right crop = synthetic.
This is the contract between art, detection hotspots, and the Field Manual wording.

| Artifact | What the player sees | Where FE puts the hotspot |
|---|---|---|
| `seam` | hair meets the air on a dead-straight line -- no strand, no taper | top of the head |
| `mirror` | both catchlights identical, pupils matched to the pixel, beauty mark on BOTH cheeks | eye band |
| `ear` | one perfectly rectangular slab from hairline to jaw -- no fold, no shadow | side of the head |
| `glasses_merge` | temple arm is a bright bar fused to the head, no gap, no contact shadow | glasses |
| `skin_band` | hard 4 px posterised step where a jaw gradient belongs | jaw / neck |
| `hands` | one solid mitt -- fingers never separate | hands on the desk |
| `straight_badge` | lanyard dead vertical, card perfectly square to the shirt | chest / badge |
| `shadow` | cast shadow thrown TOWARD the monitor light, hard-edged, stops dead | desk under the applicant |
| `no_blink` | the sheet's frame 3 is a blink for everyone else; this one never closes | whole face (time-based) |

Humans always have the human version of every one of those: stray hairs breaking the silhouette,
asymmetric eyes with a single off-centre catchlight, a shadowed ear, a contact shadow under the
glasses arm, a tilted badge, five fingers, a soft stepped cast shadow, and a blink on frame 3.
