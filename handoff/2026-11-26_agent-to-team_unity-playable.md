## What changed

1. **`unity/` is now a real Unity project in Git.**
   - `unity/ProjectSettings/` (ProjectVersion 6000.3.29f1, ProjectSettings, EditorSettings,
     EditorBuildSettings) and `unity/Packages/manifest.json` are committed.
   - `activeInputHandler: 2` (Both) so the new Input System works in the Editor and player.
   - `scripts/Promote-UnityProject.ps1` now generates the same setting; its `-Source` form still
     replaces the committed minimum with editor-generated settings before a device build.
2. **One-click setup.** `HR//0D > Setup Project (one click)` publishes art to Resources, applies
   sprite import settings, extracts the four applicant frames, builds + saves
   `Assets/Scenes/Desk.unity`, adds it to Build Settings and opens it.
3. **Play mode self-boots.** `GameBoot` (RuntimeInitializeOnLoadMethod) builds the same gameplay
   scene from `Resources/desk_layout.json` if no `DeskBootstrap` exists in the loaded scene.
4. **Shared runtime scene builder.** `DeskRuntimeScene` places hotspots, evidence overlay, stamp,
   letter page, decision controller, bootstrap, input router -- used by both editor menu and boot.
5. **Actual controls.** `GameInputRouter` uses the **new Input System** (mouse, touch, keyboard):
   click a hotspot; `L` letter; `1-5` flag/reason; `6` insufficient; `A` approve; `S` reject;
   `SPACE` continue; `R` restart after ending; `H` help; `X`/`Esc` close letter.
6. **Readable HUD.** `GameHud` shows day/trust/corruption, the applicant card, letter + five flags,
   debrief, day summary and ending. It renders only player-facing data (no truth flag/tells).
7. **Fixes:** `DeskBootstrap` now ticks observation time and wires stamp callbacks to the inactive
   stamp object; `LetterView` loads the font metrics from the correct `.json` resource and can open
   the `Paperwork` generated by `DeskSession` (shared flag set).
